# Estrategia multiproveedor

- GER: OpenLigaDB, gratis sin clave, ODbL 1.0. https://www.openligadb.de/en/license . Los datos derivados publicados se distribuirán bajo ODbL. No se importan escudos.
- Football-data.org: candidato para otras ligas; requiere clave y verificar condiciones de publicación.
- OpenFootball: respaldo sujeto a comprobación de frescura y cobertura.
- Football-data.co.uk: solo uso privado permitido y máximo dos descargas automáticas semanales; excluido del sitio público.

No mezclar partidos entre proveedores sin reconciliar identidades. No publicar datos incompletos como clasificación oficial.
